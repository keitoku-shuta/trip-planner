# Trip Together

アカウント不要で使える、グループ旅行向けの小さなプランナーです。

## できること

- 参加者の追加と、端末上での操作者の切り替え
- 予定の提案と、参加したい／行かないの意思表示
- 参加者だけの確定予定への採用（別行動にも対応）
- 日ごとのタイムライン表示
- ブラウザ内の自動保存、JSON バックアップの入出力

## 公開方法

GitHub Pages を使う場合は、リポジトリの **Settings → Pages** で `Deploy from a branch` を選び、`main` ブランチの `/(root)` を公開元に設定してください。

これは静的なプロトタイプです。共有リンクで同じデータをリアルタイム同期するには、次の段階でデータベースまたは共有用 API を追加します。
